# BiliNotes 0.2.14

> 这一版把「看笔记」变成了「用笔记」：可以框选标重点、按学科串概念、
> 三档复习；也能把电脑里的视频直接做成笔记。

## 新增

### 框选标重点

在笔记里用鼠标框选一段话，选区上方会浮出「标重点」，点一下变成黄色荧光笔；点已标的地方可以取消。

- 高亮单独存在笔记文件夹的 `highlights.json`，**不改 `notes.md`**，重新生成笔记不会丢
- 定位存的是「原文 + 前后各 20 字」而不是字符位置：重跑视频后文字有增删，大多数还能对上，对不上的直接跳过，不会标错地方
- 「下载整包」会把高亮一起带走；导出 PDF 自动带高亮
- 手机长按选字同样可用

### 本地视频也能做笔记

总览页「快速处理单个视频」多了来源切换：

```
[ B站链接 | 本地文件 ·实验 ]
```

- 点「选择文件…」弹系统打开文件框，只传路径，不复制几个 G 的视频
- 视频旁边有同名 `srt / vtt / ass` 字幕就直接用，秒级完成；没有就走本地语音转写
- 和 B 站视频进同一个任务队列，暂停、取消、重试、导出都一样
- 没有音轨的录屏（纯 PPT 录制）不会失败，自动退回「只看画面」整理
- 本地任务只允许本机发起，局域网里的手机看不到这个入口

### 概念按学科分组

概念索引新增「按学科」：数学、计算机、英语等分开看，长列表不再全堆在一起。进页面会自动给没归过类的概念补一次学科，已有的分类结果不动。

### 复习改三档，加键盘快捷键

评分从四档改成三档——**忘记 / 模糊 / 记得**，第四档改为「丢弃」：点了直接把卡删掉，之后不再出现，不参与排期。

排期也顺手调了：第一次点「记得」是 3 天后，第二次 7 天后（以前第一次是 1 天，和「模糊」看起来一模一样，容易以为坏了）。

A / S / D 对应三档，F 是丢弃，右手不用离开键盘。

## 改进

### 笔记排序支持正序 / 倒序

排序下拉从两个选项变成四个：

- 生成时间 · 新在前 / 旧在前
- 修改时间 · 新在前 / 旧在前

选择记在本机，刷新后保持；副标题会显示当前口径。收藏夹卡片上的「最近」日期仍取组内真正最新的那篇，不会因为切正序就显示成最旧的。

### 发现新版改成居中弹窗

原来是右下角轻提示条，容易被忽略。现在改成居中对话框，三个出口：**去更新 / 以后再说 / 这个版本不再提醒**。

- 「去更新」和「不再提醒」都记在本机，同一版本只提一次
- 「以后再说」只关本次，下次启动还会提
- 检查失败仍然完全静默，不弹任何框
- 点「去更新」会先退出主进程再拉安装器，避免安装时文件被占用

## 修复

### 导出 PDF 得到一张白纸

**现象**：短笔记导出 PDF 是空白页，长笔记正常。

**原因**：打印页的正文是异步取回来的，而导出工具在页面还没画完时就开始打印。长笔记只是碰巧赶在打印前渲染完了。

**处理**：导出时把笔记正文直接内联进打印页，同步渲染；同时改成等页面发出「渲染完成」标记再打印，失败自动退回原来的方式。这个修复对所有笔记生效。

## 验证

- 新增 `tests/smoke_local.py`：路径校验、`file://` 往返、探测、抽音轨、同名字幕、本地/B站导出对照
- 本地视频端到端：12 秒带字幕视频 3~5 秒出完整笔记；无音轨视频出「只看画面」笔记
- 高亮：单段、跨标题/引用块、刷新恢复、点取消、打印页带高亮，均实测通过
- 排序：四种口径 API 严格互为倒序，非法值回落默认；切「旧在前」后收藏夹 13 张卡片完全反转
- PDF：本地笔记与 B 站笔记导出均含字体与图片，不再是白纸
- 回归：api / core / cards / pipeline / single / series / quiz / concepts / frames / export / offline / ui / update 等 26 个既有套件全部通过

## 升级说明

- 覆盖安装即可，笔记、配置、API Key、卡片复习进度都不受影响
- 旧笔记不需要重新生成：高亮、排序、PDF 都是显示与导出层的变化
- 「知识点讲义」勾选框目前仍不生效（后端创建任务的入参里没有这个字段），勾了会被忽略，下一版处理
