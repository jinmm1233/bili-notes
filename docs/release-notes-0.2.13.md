# BiliNotes 0.2.13

> 双端同发：修好「整个收藏夹出不了题」和「公式里的中文显示成源码」；
> macOS 顺带补齐 0.2.11 起的全部修复。

## 修复

### 选整个收藏夹出题，提示「模型没给出可用题目」

**现象**：自测里范围选单篇笔记能正常出题；选整个收藏夹就报「模型没给出可用题目」。

**原因**：出题接口有两条取笔记的路径，单篇走 `get_note()`（带正文），合集走 `scan()`——而 `scan()` 只给列表页用的元信息，**没有 markdown 正文**。于是每篇都被当成「材料不足 300 字」直接返回空，一篇都没真正问过模型。

**处理**：两条路径统一走 `get_note()` 读正文；不存在的笔记只跳过、不拖垮整份卷子。顺带修了多篇合集时卷名永远显示「默认收藏夹」的问题。

### 画面要点里公式显示成 LaTeX 源码

**现象**：画面要点里个别条目显示成 `\begin{pmatrix}2&-1\\5&3\end{pmatrix}` 这样的源码，同一段其他条目正常。

**原因**：前端判断「是不是公式」时，有一条保护规则——`$...$` 里夹中文就当成普通文字（防止「$50 元」被误渲染）。而模型会把板书箭头旁的说明写进公式里，例如 `\rightarrow(初等行变换)`，触发这条规则后整段退回源码。

**处理**：先看有没有 LaTeX 命令（`\begin`、`\frac`、`\text`、`\xrightarrow` 等），有命令就认作公式，再看中文。纯文字和价格不含反斜杠，保护规则照旧。
