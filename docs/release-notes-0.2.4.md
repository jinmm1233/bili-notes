## BiliNotes · 把 B 站视频变成可复习的知识库

这是 BiliNotes 的第一个公开发布版本（v0.2.4）——一个运行在 Windows 上的本地工具：
把 B 站收藏夹里的视频，整理成带截图、带时间码的 Markdown 笔记，再顺着笔记做概念索引、自测卷和间隔复习卡片。

它和「只把口播转成文字」的工具不太一样：**画面上的字也会进笔记**。PPT 标题、板书、代码、公式和表格，
会从关键帧里识别出来还原成 Markdown；讲解对应哪一帧，笔记里的要点就配哪一帧，点时间码能跳回视频原位置。

### 能做什么

- **批量把视频变成笔记**：扫码登录 B 站 → 选收藏夹或合集 → 勾选视频入队；也能直接贴一个视频链接单独处理，
  不登录也能用。文本按 CC 字幕 → B 站 AI 字幕 → 本地语音转写自动降级，转写跑在本机 CPU 上，音频不上传；
  外语素材成稿时译为中文，专有名词附原文。
- **画面取得准**：在整页内容显示完整时取帧，跳过 PPT 逐条动画的中间态，同一页只留一张；纯人像、风景和黑场不进笔记。
  笔记详细度分三档，简洁每段 5 张、适中 8 张、详细不设上限。
- **笔记读得下去**：按语义切块总结成章节，配思维导图、完整转录与字幕文件；可选生成「知识点讲义」，
  按动机 → 定义 → 推导 → 例题 → 易错 → 自测重写一遍。
- **知识串得起来**：知识库按「收藏夹 → 合集 → 分集」三级浏览，同一合集折成一张卡；
  概念页把散在几集里的同一个概念归到一起，看每篇分别怎么解释。
- **记得住**：笔记可生成知识卡片，按 SM-2 间隔重复排期，复习范围可选整个库、某个收藏夹、某几篇或自定义组合；
  也能从笔记出一套自测卷，手机上做选择题。
- **适合拿 B 站学英语**：导入四六级等词库后，英语视频的笔记会标出遇到的生词，原文里的词可点/悬停看释义，
  也能把遇到过的生词变成单词卡。
- **带走和分享**：每篇笔记是 `notes.md` + 截图 + 思维导图 + 字幕文件，存在本机「文档\BiliNotes」。
  阅读器可导出 PDF、Word 或直接打印；也能导出一个离线 HTML 包，或在同一 WiFi 下扫码用手机看笔记、刷卡片。
- **界面与设置**：四套主题；设置页可配文字模型与 Key、转写档位、笔记详细度、磁盘清理和软件更新。

### 数据与运行方式

- 笔记、卡片、词库、B 站登录态和 API Key 都只存在本机。
- **软件不内置 API Key**：AI 摘要需要你在设置页填自己的模型服务 Key；不填也能用，
  会得到转写全文 + 关键画面 + 画面文字，只是没有 AI 摘要。
- 它是一个本地程序，界面在独立窗口打开。**关掉窗口程序就退出**，不后台常驻、不开机自启；
  下次从桌面快捷方式或开始菜单打开。
- 内置更新只从 GitHub Releases 检查与下载，可在设置页手动检查或关闭。

### 运行环境

Windows 10 1809+ / Windows 11，建议装有 Microsoft Edge（系统自带）。
首次做语音转写需联网下载模型（默认 base，约 145MB，走国内镜像、支持断点续传）；
纯粹看笔记和刷卡片不需要联网。语音转写与画面取字跑在 CPU 上，长视频会比较慢。
目前只支持 B 站，弹幕不参与总结。

### 下载与安装

- 安装包：`BiliNotes-setup-0.2.4.exe`（内含主程序、ffmpeg 与 VC++ 运行库）
- 大小：211.1 MB（221304194 字节）
- SHA256：`9be86df4dc96503445bc61d77bc469b8db2e43f5ac14cfaf4192a9eaeb931028`

双击运行 → 系统权限确认点「是」→ 装完从桌面快捷方式打开。
程序未做代码签名，首次运行若出现「已保护你的电脑」，点「更多信息 → 仍要运行」。
以后升级时直接覆盖安装即可，笔记、设置与词库都会保留。
