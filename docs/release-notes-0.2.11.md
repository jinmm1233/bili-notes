# BiliNotes 0.2.11

> 首次转写不用再干等：语音模型改从 ModelScope 取，国内实测快约 50 倍。

## 修复

### 新电脑首次转写提示「语音模型下载失败」

**现象**：装完第一次跑没有字幕的视频，进度停在下载语音模型，最后报「语音模型 base 下载失败（已下 X/145MB）」。

**原因**：模型默认从 `hf-mirror.com` 下载。实测这个源现在只有 **96 KB/s**，base 档 145MB 要下二十多分钟；网络稍抖就断，用户看到的就是下载失败。

**处理**：

- **换主源**：优先从 ModelScope 取同名仓库，实测 **5 MB/s**，145MB 约半分钟；
- **保留兜底**：ModelScope 不通时自动退回 `hf-mirror.com`，自建镜像只要改 `hf_endpoint` 仍然生效；
- **自动换源 + 重试**：某个源出错不会立刻失败，会换下一个源；全部失败再整体重试一轮，已下载的部分保留，继续断点续传；
- **连接快速失败**：连不上 15 秒就放弃，不再让用户对着一个死源等 3 分钟；
- **防止拼接坏文件**：服务器忽略 Range 时改为重写文件，而不是把新数据接在旧片段后面。

## 验证

- 真实下载：tiny 档 75MB 从 ModelScope 下完 **23.6 秒**（约 3.2MB/s），4 个必需文件齐全，仓库里没有的可选文件正确跳过。
- 新增 `tests/smoke_model_source.py`，10 项全过：源顺序、自建镜像、首源失败自动换源、可选文件 404 跳过、全源失败时的报错文案。
- 打包产物验收 50 项、安装包验收 21 项（与 0.2.10 同一套流程）。

## 升级说明

- 覆盖安装即可，笔记、配置、API Key 都不受影响。
