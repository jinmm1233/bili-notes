# BiliNotes 0.2.9

> 修一个「展开合集跑偏」的问题：收藏的是某门课，展开后却把整季几十门不相干的课排进队列。

## 修复

### 收藏的多P课被换成了整个大合集

**现象**：收藏《线性代数》4小时速成课（这门课本身有 10 个分P），勾选「展开合集/分P」后，队列里塞进的是「期末冲刺上大分【大学篇】」的全部 78 集——数学、物理、计算机、化学、土木、经管混在一起，压根不是这门课。

**原因**：B站的合集可以再分章节（section，界面上就是子合集），而旧逻辑做了两件错事：

1. 把合集里所有章节的分集摊平成一个列表；
2. 优先级是「合集 > 多P」，所以一个有 10 个分P的课，被整季替换掉了。

**处理**：

- **多P优先**：视频自己拆好的分P才是「这门课」，直接按分P展开；
- **单P视频**再看合集，且**只展开当前视频所在的那一章节**（例如「数学类」26 集），不再整季；
- 章节 id 写进系列 id（`5525752-6142731`），知识库里不同学科各自折叠成一张卡，不会混在一起。

## 新增

- **选集弹窗支持视图切换**：默认「本视频分P 10」，旁边一个「所属合集 7 章」；点合集视图能看到该季的全部章节（数学类 / 大学物理类 / 计算机类 …），点章节即可切换列表。
- 多章节合集在选集时会把父合集说清楚：「来自《期末冲刺上大分【大学篇】》，只展开「数学类」这一章」，避免误以为收藏错了。
- 深色皮肤（科技 / 极简）下章节标签改为跟随主题配色，不再是白底浅字。

## 验证

- 分章节展开回归测试 8 组全过（多章节、单章节、单集章节、显式切章、多P优先、切回合集）。
- 原有系列测试全过（多P / 合集识别、每合集限集、跳过已完成、失败回退）。
- 真实数据实测（`BV1Ey4y147xn`）：默认视图 = 该课 10 个分P；合集视图 = 数学类 26 集；再切计算机类 = 14 集。
- 打包产物验收与安装包验收见发布流程（全绿后发布）。

## 升级说明

- 覆盖安装即可，笔记、配置、API Key 都不受影响。
- 此前已经按「整季」导入的旧笔记仍留在旧合集卡下，不会自动拆分；之后重新导入的会按实际章节归档。
