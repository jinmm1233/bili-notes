## BiliNotes v0.2.6

把 B 站视频变成能读、能复习、能打印的 Markdown 笔记。
Windows 一键安装包，内含主程序、ffmpeg 与 VC++ 运行库，无需装 Python。

- 安装包：`BiliNotes-setup-0.2.6.exe`
- 大小：210.9 MB（221121505 字节）
- SHA256：`4700c67194bf2c586b486d07f5343be578d6e4d6334d487d17042a4848ce11bd`

### 这个版本能做什么

**一、批量把视频变成笔记**

扫码登录 B 站 → 选收藏夹或合集 → 勾选视频入队。也能直接贴一个视频链接单独处理，
不登录也能用。文本按 **CC 字幕 → B 站 AI 字幕 → 本地语音转写** 三级自动降级；
转写跑在本机 CPU 上，音频不上传。外语素材成稿时译为中文，专有名词附原文。

**二、画面取得准 —— 每一页课件只留一张图**

判断「这一帧有没有用」交给**看图模型**看画面内容，而不是靠边缘密度、清晰度这类像素指标。
它逐帧回答四件事：画面类型（板书 / PPT / 图表 / 实拍 / 界面）、值不值得进笔记、
信息量几档、**这是哪一页**。

于是：

- 纯人物、空镜、翻页糊帧不进笔记
- **同一页课件只留一张**——而且留的是内容最全的那张。
  后面那张若把这一页讲全了，前面重复的就不要
- 每张图下面直接写出这一页的标题和分点原文，一页 PPT 的内容一次说清，
  不用对着图猜老师在讲什么
- 板书会随着时间累积，模型看得见多写的那几行，所以内容真的不同的板书都保留

看图判断搭在原本就有的「提取画面要点」请求上，**不额外增加调用**。

**三、讲解对画面**

博主暂停下来补充分析、但没有字幕的那段话，会连同它对应的那一帧一起进笔记。
每条要点带真实时间码，点一下跳回视频原位置。

**四、笔记读得下去**

按语义边界切块（非固定字数）逐块摘要，再归并成章节。每篇笔记产出：

| 文件 | 内容 |
|---|---|
| `notes.md` | 正文：主题 → 子主题 → 要点，带配图与画面要点 |
| `assets/*.jpg` | 关键帧原画（低清定位后 1080p 定点重取） |
| `mindmap.html` | 可交互思维导图 |
| `subtitle.srt` | 字幕文件 |
| `meta.json` | 元数据，便于二次处理 |

可选生成「知识点讲义」，按 **动机 → 定义 → 推导 → 例题 → 易错 → 自测** 重写一遍，
单独存 `lecture.md`，阅读器里以标签页切换；老笔记可一键补生成，不重跑视频。

**五、知识串得起来**

- **概念索引**：把散在几集里的同一个概念归到一起（忽略空格、大小写、写法差异），
  按方法分层或按视频分组；点开能看它在哪几篇笔记里讲过、各篇怎么解释。
  景点地名、鸡汤口号、常识操作这些非知识条目会自动挡掉
- **知识卡片**：把笔记拆成能"考"的卡片，按 SM-2 间隔重复排期；
  复习范围可指定为全部 / 某个收藏夹 / 某几篇笔记 / 自定义组合
- **单词本**：外语视频里的生词可入词本；支持导入自己的词书文件，
  也能从笔记里一键收集生词

**六、导出与打印**

阅读器里一键导出 PDF（公式与截图原样）、Word（公式是 Word 原生公式，可继续编辑）
或直接打印。A4 排版、页脚页码、图片不跨页。

### 需要准备什么

- **Windows 10/11**（64 位）
- **一个模型 API Key**（DeepSeek / 智谱 / 通义千问等任选其一，填在设置页）
  - 没有 Key 也能用：输出转写全文 + 关键画面 + 画面文字，只是没有 AI 摘要与画面判断
- **首次运行会自动下载语音模型**（默认 base，145MB，约 1–2 分钟，走 hf-mirror 镜像并断点续传）；
  网络差可在设置里换 tiny（75MB）
- 首次转写还需下载 ffmpeg（约 92MB），设置页可一键下载

### 安装与迁移

安装包是**绿色可迁移**的：程序、ffmpeg、VC++ 运行库都打包在安装包内，
不依赖本机 Python。换一台机器直接装即可，**但本机的密钥、登录态、模型不会跟着走**：

| 内容 | 位置 | 换机后 |
|---|---|---|
| 笔记产物 | `文档\BiliNotes\` | 手动复制即可 |
| 偏好设置 | `%APPDATA%\BiliNotes\config.json` | 可复制（不含密钥） |
| API Key | `%APPDATA%\BiliNotes\secrets.dat` | **不迁移**——Windows DPAPI 加密，换机解不开，需重新填 |
| B 站登录态 | `%APPDATA%\BiliNotes\cookies.txt` | **不迁移**，需重新扫码 |
| 语音模型 / ffmpeg | `%APPDATA%\BiliNotes\models\`、`bin\` | 不迁移，首次运行自动重新下载 |

### 已知限制

- 只支持 B 站
- 无 GPU 加速，长视频转写较慢（CPU 上约为视频时长的 1/9～1/4）
- 免费看图模型高峰期会排队，此时画面判断会自动降级为纯文字线索
- OCR 对花体字、竖排文字识别率有限，笔记中已标注「可能有误」
- 弹幕不参与总结
- 收藏夹一次最多导入 200 个，超出请分批

### 安装

1. 下载上面的 `BiliNotes-setup-0.2.6.exe`；
2. 双击运行，Windows 权限确认点「是」；
3. 装完从桌面快捷方式打开。首次运行会下载语音模型与 ffmpeg，
   然后在「设置」里填一个模型 API Key、扫码登录 B 站，就能开始用了。

> 没有管理员权限的机器也能装：安装向导会问你「装给所有用户」还是「只装给自己」，
> 选后者就装到当前用户的目录，全程不需要提权。

### 校验

`SHA256SUMS.txt` 会作为资产一起上传，程序下载完会自动比对；
上面的 SHA256 也写了同一份值，两种来源任取其一都能通过。

```bash
certutil -hashfile BiliNotes-setup-0.2.6.exe SHA256
```
