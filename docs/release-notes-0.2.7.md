## BiliNotes v0.2.7

把 B 站视频变成能读、能复习、能打印的 Markdown 笔记。
本版为 Windows 安装包，不需要另装 Python。

| 平台 | 文件 | 大小 | 架构 |
|---|---|---|---|
| Windows 10/11 | `BiliNotes-setup-0.2.7.exe` | 214.3 MB（224,668,018 字节） | x64 |

SHA256：`7bd7ef2dcb351a7a1422fc649645af913c80eb2343a07cfd835660e7812c0edb`

### 本次更新

**出了新版本，软件会主动告诉你**

以前要自己打开「设置 → 软件更新」才知道有没有新版。现在启动后会静默检查一次，
发现新版本就在右下角冒一条轻提示，不打断你正在做的事：

- 点「去看看」直接跳到更新页，下载、校验、安装一条龙
- 点「×」关掉，同一个版本不再重复打扰；等真出了下个版本才会再提醒
- 正在更新页、导出学习包或打印时不会弹

**其他**

- 窗口和任务栏的小图标换成与安装包一致的正式图标

### 安装

1. 下载上面的 `.exe`；
2. 双击运行，系统权限确认点「是」；
3. 装完从桌面快捷方式打开，或在软件「设置 → 软件更新」里检查新版本。

已经装过旧版的直接覆盖安装即可，笔记、设置、单词本都会保留。

### 校验

`SHA256SUMS.txt` 会作为资产一起上传，程序下载完会自动比对；
上面的 SHA256 也写了同一份值，两种来源任取其一都能通过。
