# BiliNotes · B站视频知识库

扫码登录 B站，把收藏夹里的视频批量转成**带截图、带时间戳、带思维导图**的 Markdown 笔记。

```
扫码登录 → 拉收藏夹 → 批量入队 → 字幕/转写 → 关键画面 + 画面 OCR → 分块总结 → 笔记 + 导图
```

和同类工具最大的差别：**画面上的文字也会被识别进笔记**。PPT 标题、代码片段、公式、表格，都能从关键帧里 OCR 出来并还原成 Markdown 语法，而不是只转写口播内容。

> 继续开发前请先读 [`docs/HANDOVER.md`](docs/HANDOVER.md)：里面有完整的功能台账、关键实现细节、踩坑禁令（哪些路不要再走一遍）、数据格式、API 清单、测试纪律和下一步路线。

## 界面

左侧导航五个视图：

| 视图 | 作用 |
|---|---|
| **总览** | 笔记数、关键画面数、章节数、处理中任务；可快速处理单个视频 |
| **采集收藏** | 扫码登录 → 选收藏夹 → 勾选视频 → 批量导入 |
| **任务队列** | 实时进度、取消、重试，同时最多处理 2 个 |
| **知识库** | 笔记卡片网格、全文搜索、阅读器（含图片渲染） |
| **设置** | 模型供应商与 Key、转写档位、输出目录 |

## 能力

| 环节 | 说明 |
|---|---|
| 账号 | B站官方扫码登录，cookie 存本机，用于读收藏夹和拉 AI 字幕 |
| 批量采集 | 收藏夹分页拉取、自动跳过已处理、批量入队；合集/多P 可展开，且**每个合集能限定取几集**（跳过已做的，选 5 就补 5 集新的） |
| 概念索引 | 汇总所有笔记的「关键概念」，按概念名归并（忽略空格/大小写/写法差异）；**按方法分层**（「主对角线/倍乘」挂在「初等行变换法」下面），也可切「按视频」分组；点一个概念能看到它在哪几篇笔记里讲过、各篇怎么解释、挂了哪些卡片；自动隐藏景点地名、鸡汤口号、常识操作、例题步骤（可一键看全部，也能手动纠正） |
| 知识卡片 | 把笔记拆成能"考"的卡片（概念/公式/步骤/易错/对比），按 SM-2 间隔重复排期；**可按「全部 / 某收藏夹 / 某几篇笔记 / 自定义组合」选范围复习**，四档评分快捷键 1~4；下方「所有卡片」按收藏夹→笔记浏览全部卡片，可单张删除或立刻复习 |
| 合集选集 | 卡片悬停点「选集」→ 显示**共几集**、哪几集已有笔记；可勾选，也可直接输入 `3,5-7,11-20` 批量选，另有全选/反选/只选未做；底部「重做已做过的集」开关可覆盖重跑 |
| 文本获取 | CC 字幕 → B站 AI 字幕 → 语音转写，三级自动降级 |
| 语音转写 | faster-whisper 本地 CPU，无需显卡，音频不外传；**自动识别语种**（中文/英文/日文等） |
| 外语视频 | 外语素材成稿时译为中文，专有名词括号内附原文 |
| 关键画面 | 感知哈希检测画面切换，三路候选四维打分；**低清定位后用 1080p 定点重取**，进笔记的是原画 |
| 文本校验 | 音画互校修正同音误写（卷机→卷积），修正记录逐条写入笔记 |
| 画面文字 | RapidOCR 提取 PPT、代码、公式，还原成 Markdown 代码块/公式块 |
| 画面表格 | 用 OCR 坐标做几何聚类，把画面表格还原成真正的 Markdown 表格（不额外下模型） |
| 分块总结 | 按语义边界切块（非固定字数），逐块摘要后归并成章节 |
| 并行处理 | 转写（CPU）与画面下载分析（网络）同时进行，设置里可关闭 |
| 画面预筛 | OCR 前先按边缘密度+清晰度挡掉纯人物/风景/黑场帧，每张仅 5ms |
| 思维导图 | mermaid 嵌入正文 + 可交互 markmap 页面 |
| 知识点讲义 | 可选。按"名师备课"的路子把笔记重写成讲义（动机→定义→推导→例题→易错→自测），单独存 `lecture.md`，阅读器里以「笔记 / 讲义」标签页切换；老笔记可一键补生成，不重跑视频 |
| 界面主题 | 极光 / 极简 / 科技 / 纸感 四套皮肤，侧栏或设置页切换，记在本机 |
| 导出打印 | 阅读器里「导出 / 打印」：PDF（本机浏览器无头打印，公式与截图原样）、Word（可继续编辑，公式是 Word 原生公式）、直接打印（系统打印对话框）。A4 排版、页脚页码、图片不跨页 |
| 输出 | `notes.md` + `assets/*.jpg` + `mindmap.html` + `subtitle.srt` + `meta.json`（+ 可选 `lecture.md`） |

> 首次运行会自动下载语音模型（默认 base，145MB，约 1–2 分钟）。
> 模型走 hf-mirror 镜像并做断点续传；网络差可在设置里换 tiny（75MB）。

## 快速开始

```bash
# 1. 安装依赖（建议走国内镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 准备 ffmpeg：放到项目 bin/ 目录、确保 ffmpeg/ffprobe 在 PATH 中，
#    或在设置 → 运行环境里点「一键下载」（约 92MB，装到 %APPDATA%\BiliNotes\bin）

# 3. 启动（自动打开浏览器）
python -m app.main
```

首次使用三步：设置里选供应商填 Key → 采集页扫码登录 → 选收藏夹批量导入。

没有 API Key 也能用：输出转写全文 + 关键画面 + 画面文字，只是没有 AI 摘要。
不登录也能用：直接粘贴视频链接处理单个视频，只是拿不到收藏夹和 AI 字幕。

### 命令行

```bash
python -m app.cli BV1xx411c7mD
python -m app.cli https://www.bilibili.com/video/BV1xx411c7mD?p=2 --no-frames
```

## 为什么不用浏览器自动化

抖音/小红书那类工具通常用 Playwright 持久化浏览器扫码。B站不必如此——它有官方 passport 扫码接口：

```
POST /x/passport-login/web/qrcode/generate   → qrcode_key + 登录链接
GET  /x/passport-login/web/qrcode/poll       → 轮询状态（86101/86090/86038/0）
```

拿到的是标准 cookie，直接写成 Netscape 格式就能同时喂给 yt-dlp（拉字幕、下视频）。省掉了打包 Chromium 的 150MB+、额外的浏览器进程，也不受浏览器版本影响。

## 概念索引

一篇笔记只回答"这一集讲了什么"，概念页回答"这个概念我一共在哪几集见过"。

- 数据来源：笔记里 `## 关键概念` 的表格（主来源）+ 卡片上的 concept 字段（补充）。
- 同一个概念的不同写法会合并：`单位矩阵` / `单位 矩阵` / `单位矩阵：` 视为同一个。
- 详情里列出**每篇笔记各自怎么解释**——同一门课讲了两遍时，这里能看出两次讲法的差别。
- **按方法分层**：细节挂在所属方法下面（「主对角线/倍乘/增广矩阵」→「初等行变换法」），列表里只有方法是一级，点箭头展开细节；点方法名看它自己的详情。
- **按主题 / 按视频**两种分组可切：按主题看知识结构，按视频看某一集都讲了什么。选择记在本机。
- 顶部可筛选「全部 / 跨多篇 / 有卡片 / 只来自卡片」，也能直接搜。
- **非知识条目会被挡掉**：旅游 vlog 里的景点、TED 里的口号、`C盘`/`加括号`这类常识操作、`第二列化零`这类只在某道例题里成立的步骤、`证书x`这类变量、`IP属于NP`这类判断句，都不会混进来——后者会被并进「整数规划」这个概念的正文里。判别先用构词规则（地点后缀、鸡汤句式、常识操作、学科词），剩下的让模型带**来源笔记标题**判一次，同时判它属于哪个方法；结果长期缓存（`%APPDATA%\BiliNotes\concept_tags.json`）。默认隐藏「景点/地点」「鸡汤/口号」「常识操作」「实例步骤」「关系判断」「变量占位」六类，「未归类」保持可见；取消勾选「只看知识类」能看全部，详情里也能点「其实是知识点 / 不是知识点」手动纠正，手动结论不会被自动覆盖。

> 笔记越多、同一门课越多集，这一页越有用；只有三两篇不相干的视频时，它相当于一份术语表。

## 复习（知识卡片）

笔记解决"看得见"，卡片解决"记得住"。两者是分开的：

- 在「复习」页下方「所有卡片」里，找到笔记点 **生成卡片**，模型会把笔记拆成 10~20 张卡片。只读 `notes.md`，不重跑视频。
- **复习范围可以自己指定**：顶部下拉选「全部笔记 / 某个收藏夹 / 某篇笔记」，或点「自定义…」跨收藏夹勾几篇放在一起复习。选择记在本机，下次进来还是这个范围；范围内没有到期卡片时可以点「全部过一遍」整轮复习。
- **生成过的卡片都在「所有卡片」里**：按收藏夹 → 笔记分组，点开一篇就能看到每张卡的类型、问题、下次到期时间，可以「现在复习」或删掉。笔记没写进「关键概念」表的卡片，也能在「概念」页的「只来自卡片」筛选里找到。
- 重新生成时会把**已有题目**一起发给模型，并按相似度挡掉"换个说法问同一件事"的重复题（定位词如「第一列/第二列」「上方/下方」不同的不会被误删）。
- 卡片正面是一句能独立成立的问题，翻面看答案（支持 LaTeX 公式）。先自己回想，再翻面，这是主动回忆。
- 翻面后按四档评分：**忘记 / 模糊 / 记得 / 太简单**（键盘 1~4，空格翻面）。**每个按钮上直接写着「按下去会推到多久之后」**（如「记得 · 3 天后」），不用猜规则。
- 排期按 SM-2 简化版：忘记 → 10 分钟后重来、连击清零；模糊 → 1 天起、之后小幅递增；记得 → 1 天、3 天、再按熟练度递增；太简单 → 3 天起、增长更快。间隔最长半年，熟练度限制 1.3~2.8。点右上角「排期规则」随时看说明。
- 侧栏「复习」上的数字就是今天到期的卡片数，做完了数字消失。
- 卡片存在 `%APPDATA%\BiliNotes\cards.json`，按「笔记 + 问题」去重，重复生成不会产生重复卡片。

## 导出与打印

笔记写完后经常要打印或交作业，阅读器右上角「导出 / 打印」提供三种方式：

| 方式 | 做什么 | 依赖 |
|---|---|---|
| PDF | 用本机 Edge/Chrome 无头打印当前笔记，KaTeX 公式、关键帧、知识地图和网页里一模一样 | 需要 Edge 或 Chrome（Win10/11 自带） |
| Word | 生成 .docx：标题层级、列表、引用、表格、代码、图片都映射成原生元素，公式转成 **Word 原生公式**（可编辑） | 随包的 python-docx + latex2mathml（`vendor/`） |
| 直接打印 | 调系统打印对话框，也能顺手「另存为 PDF」 | 无 |

导出时默认**不含完整转录**（那部分通常比正文长好几倍），需要时勾选。
Word 会把同一张幻灯片的多张近似截图去重，避免打印时重复占页。

> 打印样式是独立的 `@media print`：白底黑字、A4、页边距 15mm、图片不跨页、标题不孤立在页底。

## 目录结构

```
%APPDATA%\BiliNotes\
├── config.json      # 偏好设置（不含密钥）
├── secrets.dat      # API Key，Windows DPAPI 加密，换机解不开
├── cookies.txt      # B站登录态（Netscape 格式）
├── models\          # 语音模型
├── bin\             # 按需下载的 ffmpeg / ffprobe
├── cache\<任务ID>\  # 中间产物，可安全删除
└── logs\app.log
```

笔记默认输出到 `文档\BiliNotes\`，可在设置里修改。

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller build.spec --noconfirm
# 产物 dist/BiliNotes/BiliNotes.exe，再用 Inno Setup 打成安装包
```

**不打包 ffmpeg**：完整构建的 ffmpeg.exe 有 220MB，两个 450MB，会把安装包体积翻几倍。
程序启动后检测顺序是 `随包 bin → 用户目录 bin → PATH`，都没找到时在设置页提示一键下载
（gyan.dev essentials 构建，92MB，断点续传，解压后只保留 ffmpeg.exe / ffprobe.exe）。

## 常见问题

**二维码扫了没反应**
二维码 3 分钟过期。点「获取登录二维码」重新生成；手机端需要在确认页面点「确认登录」。

**语音模型下载不动**
首次转写需联网下载模型（small 约 250MB），程序默认走 `hf-mirror.com`。若仍失败，浏览器打开 hf-mirror.com 搜 `Systran/faster-whisper-small`，整个文件夹放进 `%APPDATA%\BiliNotes\models\` 后重试。

**转写很慢**
CPU 上 small 约为视频时长的 1/9。设置里可切 `tiny`（快 3 倍）或 `base`。有 AI 字幕的视频不会走转写。

**笔记里图片太多/太少**
设置里调「每条笔记最多保留画面张数」（默认 40）。画面切换灵敏度由 `BILINOTES_SCENE_PHASH_DISTANCE` 控制，越小越敏感（默认 14）。

**硬盘被吃满了**
每条任务都会把视频和音频下载到 `%APPDATA%\BiliNotes\cache\`，一条 17 分钟的视频约 70MB。
默认策略是**处理完自动删除视频和音频**（设置页「磁盘占用 → 处理完成后」），
关键帧在生成笔记时已复制进笔记目录，清理不影响已生成的笔记。
也可以在那里看到当前占用并点「立即清理」一次性回收；改成「全部保留」则用于重跑同一视频或排查问题。

## 已知限制

- 只支持 B站
- 无 GPU 加速，长视频转写较慢
- OCR 对花体字、竖排文字识别率有限，笔记中已标注「可能有误」
- 弹幕不参与总结
- 收藏夹一次最多导入 200 个，超出请分批
- 转写与 LLM 调用尚未在真实 Key 下做端到端验证（开发环境网络受限）
