设置

软件不内置任何 API Key，每人填自己的；密钥用 Windows DPAPI 加密，只有本机本账户能解密

界面主题

四套皮肤随时换，选择会记在本机。深色/护眼主题也适合长时间看笔记。

手机访问（双端）

打开后，同一 WiFi 的手机能打开同一套界面：刷卡片、看笔记、翻概念。 必须带访问口令，同网段的人没有口令进不来。

导出学习包

导出一个 .html：笔记、图片、卡片、自测卷全在里面。微信发到手机、用浏览器打开就能用， 之后不需要电脑、不需要联网、不用同一 WiFi。有图的包十几兆，导出等十几秒。

未开启：只有这台电脑能打开

手机扫这个码直接进：地址和口令都在里面，不用手输。 第一次进去后，浏览器菜单里「添加到主屏幕」就能像 App 一样打开。

这个码不会每次变：同一台电脑、同一 WiFi、不点「换一个口令」， 扫的都是同一张图，可以截图存到手机相册。只有换了 WiFi （路由器重新分配 IP）才需要回来看一眼新码。

改监听地址要重启软件才生效；换口令立即生效（手机上要重新输一次）。 口令相当于密码，别贴在群里。

手机打不开？先在同一个 WiFi 下，再检查 Windows 防火墙：首次开启时系统会弹 「是否允许访问网络」，要选允许；没弹过的话，在「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里给 BiliNotes 打勾。

英语词库

导入四六级、考研之类的词库（CSV / TXT / JSON 都行）。导入之后， 英语视频的笔记会在转录上方列出命中的生词，原文里的词可点/悬停看释义； 没导入词库时，笔记完全保持原样，一个标记都不加。

还没有导入词库

CSV 表头认 word/单词、pos/词性、 meaning/释义/中文；TXT 每行「单词 释义」也认。 只有单词没释义的行默认会报「缺释义」——勾上「缺释义也导入」就能先收进来， 再用「AI 补释义」回填。有问题的行不会被悄悄丢掉，会告诉你第几行、为什么。

文字模型

转写润色、翻译、写摘要、标重点都用这里的模型。每家的 Key 分开存放， 在这里填的 Key 只属于上面选中的那一家。

未配置

误存了别家服务的 Key？清掉后重新填。

这把 Key 只存在你这台电脑上，调用模型时直接发往你选的服务商，软件作者的账号完全不参与。 换台电脑或换个人用，都要各自填自己的。

没有 Key 也能用：会输出转写全文 + 关键画面 + 画面文字，只是没有 AI 摘要。

处理参数

首次使用会自动下载所选模型。网络差时建议先用 tiny 跑通流程。

自动检测约多花 10 秒。若明确知道视频是外语，直接指定更稳。 外语素材成稿时会自动译为中文，原文写在括号里。

转录润色

在生成"完整转录"时调优文本，需要已配置模型 Key 才生效。

只对非中文视频生效，中文视频不受影响。选"只原文"就不额外花模型额度做翻译。

各家模型改名很勤、控制台里也不一定列出老型号。默认给你的是实测能用的那个； 如果你在控制台里看到的名字不一样，直接改成你看到的那个。

未配置

这把 Key 存在看图服务商自己的槽位，不会覆盖上面的文字模型 Key。

磁盘占用

视频和音频是体积最大的中间产物：一条 17 分钟的视频约 70MB， 处理完就没有任何步骤再读它。关键帧在生成笔记时已复制进笔记目录， 所以清理缓存不会影响已生成的笔记。

关于

BiliNotes 把视频、字幕、画面文字合成一份结构化笔记：
关键帧由感知哈希检测画面切换后择优截取，
PPT / 代码 / 公式经 OCR 还原成 Markdown，
分块总结后自动生成思维导图。

全部处理在本机完成，只在你配置了模型时才会把文字发给对应服务商—— 用的是你自己填的 Key，消耗的是你自己的额度，软件不内置、也不代收任何 Key。

关掉窗口 = 程序退出，浏览器里那个 127.0.0.1 地址随即失效。
下次请从桌面图标或开始菜单打开，不要把本地地址存成书签； 它不会在后台常驻，也不会开机自启。
手机扫码的局域网地址同理：只在软件开着、且两台设备连同一 WiFi 时有效。

复习是怎么排期的

用的是 SM-2 的简化版。你按哪一档，决定这张卡下次什么时候再来—— 按钮上会直接写出「按下去会推到多久之后」。

忘记10 分钟后再来一次，连击清零、熟练度下调
模糊先放 1 天；之后每次间隔只小幅增长
记得第 1 次 1 天、第 2 次 3 天，之后按熟练度递增
太简单起步 3 天，熟练度上调，之后增长更快

间隔最长半年；熟练度（ease）限制在 1.3~2.8——忘得越多，这张卡来得越勤。 复习中卡片会自动往下走、今天的到期数递减；全部过完会提示「今天的复习完成了」。
